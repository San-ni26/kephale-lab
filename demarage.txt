Pour Android, vous avez deux excellentes options selon la façon dont vous souhaitez tester l'application :

1. Créer un fichier APK (Le plus simple et rapide pour tester)
C'est l'idéal pour l'installer directement sur votre téléphone Android ou l'envoyer à vos amis sans passer par le Play Store. D'après votre fichier eas.json, votre profil preview est déjà parfaitement configuré pour générer un APK !

Dans le terminal, lancez :

bash
cd apps/mobile
eas build -p android --profile preview
À la fin du build, EAS vous donnera un lien ou un QR Code pour télécharger et installer le fichier .apk directement sur le téléphone.

2. Créer un AAB pour Google Play Console (Si vous voulez utiliser le système de test officiel)
Si votre but est de publier l'application en "Test Interne" ou "Test Fermé" sur le Google Play Store (l'équivalent de TestFlight chez Android), vous devez générer un format .aab.

Lancez la commande avec le profil de production :

bash
cd apps/mobile
eas build -p android --profile production
À la fin, vous téléchargerez le fichier .aab que vous pourrez importer dans la Google Play Console.

(Note : Dans les deux cas, l'application Android se connectera automatiquement à votre nouveau backend hébergé sur Prisma Compute !)
